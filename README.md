# SoberFlare

Rethinking information distribution in the AI era.

SoberFlare is a Web3 social app centered around address-based identity. We are exploring how content, relationships, chat, and capital flow can live inside one unified social experience, while also rethinking how information should be distributed in the AI era.

`中文说明` 请查看 [README.zh-CN](./README.zh-CN.md)。

## What This Repo Is

This repository is the public-facing showcase layer for SoberFlare. It is designed to help judges, collaborators, and visitors quickly understand the product direction, release status, and high-level architecture.

It intentionally does **not** include the full production implementation or the core engineering details that would make the project easy to replicate directly during the hackathon.

## Core Product Flow

- `Home`: incentive-driven content distribution with on-chain boosting
- `Network`: interpretable relationship graph built from address identity and real interaction
- `Contacts`: actionable address-based contact layer
- `Chat`: E2EE direct messaging, E2EE private groups, and regular group chat
- `Me`: profile, assets, transfers, receive flow, transfer history, and swap entry
