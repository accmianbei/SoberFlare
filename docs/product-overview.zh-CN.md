# 产品说明

SoberFlare 是一个以地址身份为核心的 Web3 社交应用。我们想做的不是把传统社交搬到链上，而是把地址、关系、内容、聊天和资金流放进同一个产品结构里，让用户既能表达、连接，也能直接完成链上互动。与此同时，我们也在探索 AI 时代下新的信息分发方式，去思考什么样的内容更值得被看见，以及它应该如何被持续地看见。

也许音频和画面演示不一定完全在时间轴上一致，二者可以互做补充。

## Home

Home 是内容分发层，也是我们这次最想重点展示的页面之一。

这里不是一个只按时间倒序滚动的信息流，也不是一个围绕 KOL 和中心化推荐位组织的 feed。我们更关心的是，真正有价值的内容为什么会被看到，以及它能不能被持续看见。基于这个目标，我们已经做出了多频道 feed、发帖、评论、详情页，以及围绕帖子展开的一整套互动链路。

更重要的是，我们把链上激励机制接进了内容系统。帖子不仅可以被点赞和评论，还可以被继续“添油”。在 SoberFlare 里，用户可以用真实资产为值得被看到的内容加热。我们当前接入的 Tempered Blaze 机制支持用 COAL 或 USDT 作为起始注入，后续其他用户也可以继续为同一条内容助燃。这样一来，内容获得曝光不再只是情绪驱动或者刷存在感，而是和真实投入绑定在一起。

我们希望 Home 最终承载的是一种新的内容逻辑：有价值的帖子不只被发布出来，还能在后续互动里不断获得新的能量、回流和再分发。

## Network

Network 是第二条核心主线。它不是关注列表，也不是一张静态的人脉图，而是一张围绕地址身份展开的可解释关系网络。

我们会把多链地址之间的转账行为，以及加密聊天中地址之间的信息来往条数，逐步投影成关系强度、关系状态和角色标签。也就是说，用户看到的不只是“我认识谁”，而是“我和谁之间真的发生过什么”、“哪些连接已经稳定”、“哪些关系正在升温”。

在产品表达上，Network 更像一个动态场，而不是简单的节点列表。它帮助用户理解自己的社交结构，也允许用户进一步查看别人的关系网络，从而发现更多值得继续深入的可信连接。相比传统 Web2 社交里模糊的关注关系，我们更希望这里呈现出一种基于真实行为沉淀出来的关系图谱。

这里的设计目标很重要：这种关系扩展模式，恰恰是因为底层通信隐私被保护住了才成立。正因为私聊和私密群聊内容是加密的，用户不必担心自己的私密沟通会以明文形式暴露出去。系统并不会暴露消息内容，而是依靠真实来往与真实互动条数形成的关系信号，帮助用户更放心地拓展可信的人际关系。

## Contacts

Contacts 是关系沉淀和动作转化的中间层。它把抽象的地址关系进一步整理成可管理、可回访、可操作的联系人系统。

在这个页面里，用户可以查看已经保存的联系人，也可以查看自己加入的群组。每个联系人都可以继续进入更具体的资料页，在那里用户可以收藏地址、编辑备注、复制地址、发起私聊、直接跳转转账，或者继续查看这个人的关系网络。

这部分设计的意义在于，把“地址”从一串冷冰冰的字符串变成可识别、可维护、可持续互动的对象。Contacts 不是单纯的通讯录，它是链上身份进入真实社交关系的承接层。

## Chat

Chat 是关系真正发生的地方。我们当前已经打通了端到端加密私聊、端到端加密私密群，以及普通群聊。

用户可以直接通过地址添加联系人、发起私聊、创建群聊、加入群组，也可以在会话列表里管理自己的日常沟通。对于更敏感的沟通场景，我们的私聊和私密群都支持 E2EE，而普通群聊不采用同样的加密方式。私钥和解密材料保存在本地设备，不上传云端。这样做的目的很明确：我们希望关系网络可以被理解，但私密沟通本身不应该因此变成平台可读的数据。

所以 Chat 在 SoberFlare 里的角色，不只是“消息功能”。它是关系验证、关系维持和关系升级的发生现场，同时也和 Contacts、Network 形成闭环。

## Me

Me 是个人与钱包的合并入口，也是这次导航里和转账最相关的页面。

这个页面一方面承载个人资料，包括头像、显示名和标签；另一方面，它也是用户进入钱包能力的总入口。当前我们已经在这里放进了几类核心动作：`资产展示`、`转账`、`转帐历史`、`收款` 和 `Swap`。

转账部分支持多链资产发送，当前链路已经覆盖 Ethereum、Bitcoin、Solana、BNB Smart Chain 和 Tron。用户本地持有密钥并完成签名，服务端负责帮助构造 unsigned transaction 和广播 signed transaction。这样既保留了自托管的钱包控制权，也让转账流程能够更顺畅地嵌进社交产品里。

收款部分可以直接展示当前钱包地址和收款二维码，方便面对面或跨应用收款。Swap 页面已经接入跨链路由能力，允许用户在不同链和资产之间快速查看兑换路径。

另外，Me 页面还会展示近期转账记录，方便用户快速回看自己本机已经发起并广播的链上转账。这一点很重要，因为我们并不想把钱包能力做成一个孤立工具，而是希望它自然地嵌入个人身份和社交行为之中。

## 总结

SoberFlare 想解决的问题很直接：今天的链上身份、社交关系、内容分发和资金操作仍然是分裂的，而在 AI 时代，我们也需要重新思考信息应该如何被分发、什么样的内容更值得被看见。我们的做法，是把它们重新组织进一个统一的产品结构里。

从 Home 的内容激励，到 Network 的关系图谱，再到 Contacts、Chat 和 Me 里的地址社交与转账能力，我们希望 SoberFlare 最终呈现的是一种真正原生于链上身份的社交体验。
